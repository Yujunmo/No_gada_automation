프론트엔드 결정 사항

네비게이션: 기존 사이드바에 새 항목 "영향도 검사" 추가 (SQL Bench, Table Extractor와 같은 톤 유지)
상단: 테이블명 입력 텍스트박스 + 검색 버튼
검색 결과: 그 테이블을 참조하는 DBIO를 플랫 리스트로 먼저 보여줌 (모듈까지 한 번에 다 찾지 않음)
DBIO 항목: 기본은 접혀 있고(모듈 미조회 상태), 클릭해야 그때 연결된 모듈을 조회하는 지연 로딩 방식 — 클릭 시 스피너("모듈 조회 중…") → 펼쳐짐
펼친 내용 구성:
상단에 타입별 개수 배지(비즈 N · 서비스 N · 배치 N)로 요약
그 아래 트리 하나에 비즈/서비스/배치를 섞어서 나열, 각 항목 앞에 타입 태그(BIZ/SVC/BAT)
재귀 확장: 비즈모듈 항목만 화살표가 붙어 클릭 가능 — 클릭하면 그 비즈를 부르는 상위 모듈이 들여쓰기로 펼쳐지고, 다시 비즈면 계속 타고 올라갈 수 있음. 서비스/배치는 항상 최상위라 확장 불가(끝)
캐싱: 한 번 조회한 DBIO/비즈 노드는 다시 클릭해도 재조회 없이 열기/닫기만 토글
새로고침: 각 결과 하단에 "N분 전 조회됨 + 새로고침" — 수동으로 재조회 가능
빈 상태: 연결된 모듈이 하나도 없으면 별도 안내 문구
디자인: 기존 앱 디자인 시스템(색상/폰트/컴포넌트 스타일) 그대로 재사용, 새로운 룩 안 만듦
